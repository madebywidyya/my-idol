A LITTLE WORLD OF TIAN XIWEI — ULTIMATE VERSION

Isi:
- index.html: halaman utama
- pursuit-of-jade.html: halaman khusus Pursuit of Jade
- style.css: semua styling + dark mode + responsive + animasi
- script.js: scroll reveal, parallax/tilt, filter, gallery lightbox, dark mode, progress bar, ambient chime
- data.json: data profil, timeline, karya, karakter favorit, gallery
- images/: foto Tian Xiwei yang kamu kirim

Cara pakai:
1. Ekstrak ZIP.
2. Buka index.html.
3. Untuk pengalaman terbaik di VS Code, gunakan Live Server.
4. Tombol ♫ membuat bunyi ambient kecil langsung dari browser (tidak perlu file MP3).
5. Kalau ingin musik sungguhan, kamu bisa mengganti fitur itu nanti dengan file MP3 sendiri.
